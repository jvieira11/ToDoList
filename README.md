# 📝 Lista de Tarefas

Lista de tarefas feita com HTML, CSS e JavaScript puro, sem frameworks. Projeto para praticar manipulação do DOM.

🔗 **Demo:** https://jvieira11.github.io/ToDoList/

## Funcionalidades

- Adicionar tarefas pelo campo de texto
- Remover tarefas clicando no ⓧ

## Tecnologias

- HTML5
- CSS3
- JavaScript (DOM)

## Como rodar

Basta abrir o `index.html` no navegador, ou clonar o repositório:

```bash
git clone https://github.com/jvieira11/ToDoList.git
```
